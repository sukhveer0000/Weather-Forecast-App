# Weather Forecast App 🌦

A **Flutter-based Weather Forecast App** that provides real-time weather updates for your current location and any other city, including a **5-day forecast**. The app handles **permissions, network status, and dynamic weather data** using clean architecture principles and state management.  

---

## Features ✅

- **Current Location Weather** – Automatically detects your location and shows current weather conditions.  
- **City Search** – Check weather for any city around the world.  
- **5-Day Forecast** – Displays upcoming weather trends with daily summaries.  
- **Network Connectivity Handling** – Detects network status and shows appropriate alerts.  
- **Permission Management** – Requests location permissions safely using **Geolocator**.  
- **Clean & Responsive UI** – Weather icons and visuals adapt to different screen sizes.  
- **State Management** – Implemented using **Provider** for scalable, maintainable code.
